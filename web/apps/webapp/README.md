# web/apps/webapp

The in-browser Sigil web app — a **pre-audit / UNAUDITED DEV demo**, not deployed
and no-index. It runs the real `libsigil` `sigil-core` client-side via WebAssembly
(the `@sigil/wasm` workspace package) and demonstrates a live RFC 6238 TOTP code
computed in wasm. A full authenticator UI is a later phase. **Do not store real
secrets.**

## Conventions

Mirrors `apps/marketing`: Next.js 15.1.6, React 19, TypeScript strict, Tailwind 3,
app router, and the SAME stealth no-index posture — `X-Robots-Tag` headers in
`next.config.mjs`, `app/robots.ts` disallowing everything, and `robots` metadata
in `app/layout.tsx`. `next.config.mjs` additionally sets
`webpack.experiments.asyncWebAssembly = true` so the bundler-target wasm import
resolves.

## Build

The webapp depends on `@sigil/wasm` (`workspace:*`), whose bundler-target bindings
are generated by wasm-pack. The `build` script has a `prebuild` that builds
`@sigil/wasm` first, so `pnpm --filter webapp build` is self-contained:

```bash
corepack pnpm --filter @sigil/wasm build   # (also run automatically by prebuild)
corepack pnpm --filter webapp typecheck
corepack pnpm --filter webapp lint
corepack pnpm --filter webapp build
```

The root `web` scripts (`build`/`lint`/`typecheck`) still target **marketing only**
and are unchanged — the webapp is built via its own filter.

## Runtime proof

A Playwright headless-chromium smoke (`tests/wasm.spec.ts`) loads the built app,
pins the clock with `?t=59`, and asserts the wasm-computed RFC 6238 test-vector
code (`287082`) renders in the DOM — proving the wasm actually executed in a real
browser, not just that `next build` compiled.

```bash
corepack pnpm --filter webapp build
corepack pnpm --filter webapp exec playwright install chromium
corepack pnpm --filter webapp test:e2e
```
