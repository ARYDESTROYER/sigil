        Your account (which devices are yours)
        
    
          An account is the group of your own devices. It is what a
          subscription and a vault’s ownership belong to, so paying on one
          device covers the others and revoking one device does not orphan the
          vaults it created. It holds no email, no password and no key.
        
    
        
    
          
          
          
        
    
        
    
        
    
          Shown once. Anyone who reads this before it expires can join your
          account. The dev transport is plain HTTP — treat it like a
          password and paste it straight into the other device’s
          enrollment token field.
        
    
        
    
        
    
          Joining grants authorization only. A device that has
          just joined can sign in, but it reads nothing until you share a vault
          key to it below. There is no recovery: if you lose
          every device in an account, the account and its vaults are gone.
          Any member can invite and can revoke any other member.
        
    
        
    
          
          
          
        
    
      
    

      
    
        This vault on the server
        
        
        
    
          Convert to shared re-seals this vault under a fresh
          random 32-byte key so it can be shared. Your password is never
          shared, wrapped or uploaded — and the conversion is one-way.
        
    
        
    
          
          
          
        
    
      
    

      
    
        Share with another device
        
    
          The vault key is wrapped to that device's published hybrid public key
          (X25519 + ML-KEM-768) and relayed as ciphertext. Fingerprints are
          shown so both devices can confirm they hold the same key; the key
          itself is never displayed.
        
    
        
    
          
          
          
          
          
          
          
          
        
    
        
    
          
        
    

        
        
    
        
    
          Verify a key before the first share. Sharing pins the key it
          sees the first time; if it ever changes, sharing is REFUSED. Pinning cannot
          protect that first contact — only comparing these digits with the other
          person, over a channel the server does not control, can.
        
    
        
    
          
          
          
        
    
        
    
        
    
          
        
    

        
        
    
          REFUSED — that device’s key has CHANGED.
          
    
          
    
          
    
            Nothing was shared and no key was wrapped. Read the
            presented digits to that device’s owner over a channel
            the server does not control. Re-pin ONLY if they match what the owner
            reads back.
          
    
          
    
            
            
          
    
        
    

        
    
        
    
          Rotate. Draws a fresh vault key, re-seals this vault under it,
          re-wraps it to exactly the devices you list and deletes every other
          device’s envelope. Use it after revoking a device. It protects
          future content only — a device that already unwrapped the old
          key keeps whatever it had already copied. The vault locks afterwards.
