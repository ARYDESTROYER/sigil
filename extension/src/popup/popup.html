    Sync (dev)

    Round-trips the sealed container through a local dev sigild op-log over plain HTTP. The server only ever sees opaque bytes. If that sigild has device auth on, enroll below and every request is signed by this device’s Ed25519 key (computed in the wasm).

    Device identity

    Not enrolled — sync requests are unauthenticated.

    Sharing (dev)

    Share this vault with another enrolled device. A shared vault is sealed under a random 32-byte vault key, and that key is wrapped to the recipient’s hybrid public key (X25519 + ML-KEM-768). Your password is never shared or wrapped — the server relays an opaque envelope it cannot read. Uses the Server URL and Vault id from Sync above.
